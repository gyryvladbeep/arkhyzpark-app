# Архызпарк — мобильное приложение (прототип)

Демо-версия приложения для ООО «Архызпарк»: дневник путешественника, трекер катания и походов, достижения, бронирование инструкторов и гидов.

Это прототип на демо-данных: бэкенда нет, движение в трекере моделируется, все имена, отзывы и цифры выдуманы.

## Стек

- Expo SDK 57, React Native, TypeScript
- Expo Router (навигация, файлы экранов в `src/app`)
- react-native-svg (схемы трасс и маршрутов, значки достижений)

## Структура

```
src/
  app/                экраны (каждый файл — отдельный экран)
    (tabs)/           нижние вкладки: Дневник, Награды, Трекер, Бронь, Профиль
    session/[id].tsx  запись дневника
    achievement/[id]  карточка достижения
    ...
  components/         общие элементы интерфейса, схемы карт
  data/               демо-данные, трассы, маршруты, каталог достижений
  logic/              подсчёт статистики и достижений, состояние приложения
  theme/              цвета и отступы
```

## Запуск на телефоне (Expo Go)

1. Установить Node.js LTS: https://nodejs.org
2. Установить на iPhone приложение Expo Go из App Store.
3. В папке проекта:

```
npm install
npx expo start --tunnel
```

4. Отсканировать QR-код камерой iPhone.

## Запуск в браузере

```
npx expo start --web
```

## Тестирование

### Unit-тесты обработки GPS

```
npm run test:geo
```

Проверяют подсчёт спусков, перепада, набора высоты, привалов и фильтрацию шума на синтетических треках из `test-data`.

### GPS на Android-эмуляторе без выхода из дома

1. Запустить эмулятор в Android Studio и приложение в нём (`npx expo start`, клавиша `a`).
2. В эмуляторе: три точки на боковой панели (Extended controls) → Location → Routes → Import GPX/KML.
3. Выбрать `test-data/arkhyz-ski-3-runs.gpx` (зима, 3 спуска) или `test-data/arkhyz-hike-16km.gpx` (лето, поход).
4. В приложении: Трекер → GPS → «Начать», затем в эмуляторе нажать Play route. Скорость воспроизведения можно увеличить.

### Экран «Для тестировщика»

Профиль → «Для тестировщика»: статусы разрешений, хранилище, буфер трекера, тестовые уведомления, сброс данных.

### Что работает в Expo Go, а что только в полной сборке

- Expo Go: запись GPS при открытом приложении, разрешения, сохранение данных, локальные уведомления.
- Полная сборка (EAS Build): запись с выключенным экраном (фоновая геолокация, foreground service на Android).

### Тесты миграций хранилища

```
npm test
```

Запускает все unit-тесты: обработку GPS и миграции данных между версиями приложения.

### Сценарии для ручной проверки

- **Первый запуск.** Профиль → «Для тестировщика» → «Показать знакомство заново».
- **Офлайн.** «Для тестировщика» → «Имитация офлайна» → отправить заявку → закрыть приложение → открыть → выключить имитацию. Заявка должна уйти одна, без дубля.
- **Сбои сервера.** «Сбои сервера» 50% → отправить заявку → в «Мои брони» видно попытки и паузы между ними.
- **Падение экрана.** «Вызвать тестовую ошибку» → должен открыться экран «Что-то пошло не так».
- **Приватность трека.** Запись с GPS-треком → «Как видят другие».
